## Project Overview

Rainbow Rights South Africa is a non-profit organisation website created to promote equality, dignity, inclusion and human rights for LGBTQIA+ communities throughout South Africa.

The website provides:

- Educational resources
- Legal support information
- Counselling information
- Community awareness campaigns
- Volunteer registration
- Donation opportunities
- Contact information
